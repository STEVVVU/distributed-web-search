# Distributed web search

Node 25 ESM search service on the retained MIT MapReduce runtime. Install the pinned parse5 dependency with `npm ci`. `npm run check` validates source syntax. `npm test` preserves the original runtime's separate-process HTTP and crash-recovery checks. `npm run verify` drives the owned crawl, exact inverted index, global and topic-focused PageRank, retrieval, negative pages and restart. `npm audit --audit-level=low` checks the locked dependency tree. CI runs these commands on Windows and Linux and retains `.runs/` evidence.

Read `.agents/skills/verify-distributed-web-search/SKILL.md` for the search lifecycle and `.agents/skills/verify-rillmap/SKILL.md` for the underlying runtime. `npm run dev` launches a loopback fixture, coordinator, two workers and index builder with matching allowlist/token/storage settings; Ctrl+C or `stop` followed by Enter stops only those owned children. Keep generated data under ignored `.runs/`. Reuse `tools/processes.mjs` for owned child deadlines and cleanup; failed checks must retain `passed:false` evidence.

Trusted modules in `jobs/` export `map(key,value)` returning pairs and `reduce(key,values)` returning a JSON value. Do not evaluate remote code. Preserve task fencing, accepted-attempt fencing, exclusive coordinator ownership and durable publication ordering. Preserve the original runtime API and verification checks. Search snapshots publish atomically only after a complete successful crawl/index/rank build. All crawling uses owned synthetic loopback fixtures with enforced origin, URL, time, byte, depth and page bounds. Query term dictionary access must use own properties.

Browser verification uses CUA only. Follow `.agents/design-reference.md` for selected online reference components, matching-viewport comparison and documented functional departures. Retain accessible search labels, policy controls, readiness, error/empty states and numeric scores. Update `features/README.md` when changing a mapped user path.
