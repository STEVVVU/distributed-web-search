# Feature map

| Feature | Real path | Evidence |
| --- | --- | --- |
| Owned-graph scaling | `tools/benchmark-search.mjs` → actual bounded builder/coordinator/workers; `tools/k6-search.js` → HTTP query API | Node proves all fields/ranks against an independent oracle before retaining raw-body hashes; native k6 SHA256 validates the immutable trial. Actual wrong-hash/changed-body controls fail. Fixed256VUs/native metrics preserve dropped, interrupted, timed-out and failed outcomes; issued request duration excludes dropped offers; five-repeat matrix, synthetic relevance, resources, restart/cleanup and smoke remain distinct |
| Bounded distributed crawl | fixture HTTP server → `tools/build-index.mjs` → `crawl-page` MapReduce job → durable coordinator accepted outputs | driver checks five-page graph/text oracle, duplicate/fragment/off-origin/invalid links, malformed HTML, dangling page, both workers; negative jobs reject failed/redirect/oversized/slow/non-HTML pages while preserving snapshot |
| Complete inverted index | `index-document` MapReduce jobs → complete snapshot term set | driver checks every posting field and exact term-set equality, with no extra terms |
| Global and topic-focused PageRank | repeated `rank-contribution` MapReduce jobs → two persisted rank profiles | independent dense transition matrix checks every rank, convergence, dangling redistribution, nonuniformity and topic bias beyond two iterations |
| Search and restart | coordinator `/api/search`, `/api/status`, `/`; `web/index.html` | independent fixture postings/ranks check both policy scores/order, empty/unknown/repeated/prototype queries, input bounds,503 without index, restart retention; CUA drives actual rendering and errors |
| Owned launch and bounded failure | `npm run dev`; builder deadlines; shared `tools/processes.mjs` lifecycle | verifier proves no-worker timeout, no failed publication, retained `passed:false` failure evidence and owned cleanup; interactive launcher prints ready URL and accepts Ctrl+C or `stop` |
| Latest search wins | actual inline script request fence | `tools/verify-ui.mjs` defers responses in a Node VM DOM-consumer unit harness and asserts the newest query/policy survives older success/failure; main CUA remains separate rendered evidence |
